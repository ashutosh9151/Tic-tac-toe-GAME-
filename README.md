'''# 🎮 Tic Tac Toe - Ultimate Edition
A stunning, interactive Tic Tac Toe game with modern glassmorphism design, smooth animations, and full responsiveness.

## ✨ Features
- 🎨 **Modern Glassmorphism UI** - Beautiful frosted glass design with animated gradient background
- 📱 **Fully Responsive** - Works perfectly on desktop, tablet, and mobile devices
- 🏆 **Score Tracking** - Keep track of wins across multiple games
- ✨ **Smooth Animations** - Cell pop-in effects, particle explosions, and winning line animations
- 🎉 **Victory Modal** - Celebrate wins with an elegant popup
- ♿ **Accessible** - Keyboard navigation and screen reader support
- 🌈 **Dynamic Styling** - Color themes change based on current player

## 🛠️ Tech Stack
- HTML5 (Semantic markup)
- CSS3 (Glassmorphism, Animations, Grid, Flexbox, Custom Properties)
- JavaScript (ES6+, DOM Manipulation, Game Logic)

## 🚀 Installation
1. Clone this repository
2. Open `index.html` in your browser
3. Start playing!

## 📁 Project Structure
```
tic-tac-toe/
├── index.html       # Main HTML with score tracking & modal
├── style.css        # Modern glassmorphism styling + animations
├── script.js        # Complete game logic with win detection
├── README.md        # Project documentation
```

## 🎮 How to Play
1. **Player X** goes first - click any empty cell to place ❌
2. **Player O** follows - click any empty cell to place ⭕
3. Get three in a row (horizontal, vertical, or diagonal) to win!
4. Track your scores across multiple rounds
5. Use **New Game** to restart the current round
6. Use **Reset Score** to clear all statistics

## 🎯 Highlights
- **Animated Background**: Floating gradient orbs create depth
- **Particle Effects**: Burst of particles when placing marks
- **Winning Line**: Animated line drawn through winning combination
- **Responsive Design**: Adapts beautifully to any screen size
- **Accessibility**: Full keyboard navigation support
